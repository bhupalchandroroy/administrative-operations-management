# Administrative Operations Management

### Administrative Operations | Document Control | Task Tracking | Google Workspace Automation

A practical, portfolio-ready demonstration of administrative operations management using Microsoft Excel, Microsoft Word, Google Drive, and Google Apps Script.

This project illustrates how structured workflows, organized documentation, centralized tracking, and lightweight automation can support efficient day-to-day business operations.

## 🎯 Project Overview

Administrative teams often manage tasks, documents, communications, and reporting across multiple tools. Without consistent procedures, it becomes difficult to track responsibilities, maintain accurate records, and organize information.

This demonstration project presents a structured administrative operations toolkit designed to address those challenges.

**Project objectives:**
- Organize and monitor routine administrative activities.
- Maintain structured task and document records.
- Support consistent document naming and filing practices.
- Standardize administrative processes using SOPs.
- Demonstrate automated Google Drive folder setup.
- Provide a reusable starting point for an administrative workspace.

## 🧩 Key Project Components

### 1. Administrative Operations Control Centre

**Tool:** Microsoft Excel

A workbook containing administrative management resources, including:

- Operations dashboard
- Task tracker
- Document register
- Communication log
- Usage guidance

**Purpose:** Provide a centralized view of administrative records and ongoing work.

[View Excel Control Centre](Administrative_Operations_Control_Centre.xlsx)

### 2. Standard Operating Procedures and Google Drive Guide

**Tool:** Microsoft Word

A document outlining an approach to administrative process standardization and digital file organization.

**Included topics:**
- Recommended Google Drive folder structure
- Document naming conventions
- Daily and weekly administrative procedures
- Implementation checklist
- Document organization practices

**Purpose:** Promote consistency, clarity, and repeatable administrative workflows.

[View SOP and Drive Guide](Administrative_Operations_SOP_and_Drive_Guide.docx)

### 3. Google Drive Folder Automation

**Tool:** Google Apps Script

A starter script designed to create a predefined administrative folder structure inside a selected Google Drive parent folder.

The script checks whether each named folder already exists before creating it.

**Proposed folders:**

- `00_READ_ME_AND_TEMPLATES`
- `01_MANAGEMENT`
- `02_OPERATIONS`
- `03_CLIENTS_AND_SUPPLIERS`
- `04_HR_CONFIDENTIAL`
- `05_FINANCE_RESTRICTED`
- `06_PROJECTS`
- `07_ARCHIVE_READ_ONLY`

**Purpose:** Demonstrate how a repeatable folder setup process can reduce manual configuration.

**Important:** Folder names alone do not enforce access permissions. Confidential and restricted folders require appropriate Google Drive sharing controls.

[View Google Apps Script](create_admin_workspace_folders.gs)

## 🚀 Getting Started

### Explore the Excel Workbook

1. Download `Administrative_Operations_Control_Centre.xlsx`.
2. Open the file in Microsoft Excel.
3. Review the dashboard, task tracker, document register, and communication log.
4. Explore the sample records and workbook guidance.
5. Optionally upload a copy to Google Drive and open it with Google Sheets.
6. Check formulas, formatting, and data validation after conversion.

### Review the Administrative SOPs

1. Download `Administrative_Operations_SOP_and_Drive_Guide.docx`.
2. Open the document using Microsoft Word.
3. Review the folder structure, naming rules, routine procedures, and implementation checklist.
4. Adapt the guidance to a fictional or authorized business scenario.

### Test the Google Drive Folder Script

1. Create a separate test folder in Google Drive.
2. Open a project at [Google Apps Script](https://script.google.com/).
3. Copy the contents of `create_admin_workspace_folders.gs` into the script editor.
4. Replace `PASTE_PARENT_FOLDER_ID_HERE` with your test folder's ID.
5. Run `createAdminWorkspaceFolders` and authorize the required permissions.
6. Check the created folders and execution logs.

Always test using a designated demonstration folder before using the script in an operational environment.
